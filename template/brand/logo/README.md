# Your mark

Drop your logo here. `logo.svg` if you have a vector version, `logo.png` if you
do not. Then point `brand/brand.json` at it:

```json
"logo": "brand/logo/logo.svg"
```

If you have no logo, leave it empty and set `logo_text` instead. A wordmark set
in your own display font is a perfectly good mark, and most writers are better
served by their name than by a symbol nobody recognizes yet.
